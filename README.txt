READY-MADE FRESH TASK MANAGER

You do NOT need MongoDB, MongoDB Atlas, .env, npm install, or the old project.

1. Extract this ZIP.
2. Double-click START_TASK_MANAGER.bat.
3. The browser opens automatically.

Requirements:
- Node.js must already be installed.
- Uses a completely new backend on port 5050.
- Data is stored locally in data.json.

Features:
- Sign up
- Login/authentication
- User-specific tasks
- Add
- Edit
- Delete
- Complete/uncomplete
- Responsive design
